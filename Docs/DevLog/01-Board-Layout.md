# 01 · 보드 배치

## 중앙선 비율

1. **적용 대상** — 홈플레이트, 내야 다이아몬드, 중앙 펜스.
2. **적용 이유** — 완구형 야구 보드처럼 고정 탑뷰에서 공과 타격 지점을 함께 보기 위해서다.
3. **구조 · 설계값** — 홈 (0, 0, 0), 1루 (4, 0, 4), 2루 (0, 0, 8), 3루 (-4, 0, 4). 보드 표면은 Y=0이며 +Z가 외야다. 중앙 펜스의 필드 쪽 면은 Z=16으로, 중앙선 거리를 8:8로 맞췄다.
4. **장단점** — 프로야구장을 그대로 축소하는 방향은 내·외야의 공간 차이를 보여 주지만, 이 화면에서는 내야와 타격 구간이 작아진다. 1:1은 내야를 크게 보여 주는 대신 외야 깊이를 압축한다.
5. **구현 과정** — 완구 보드의 둥근 외야와 가까운 조작부를 출발점으로 삼았다. 프로야구장의 깊은 외야를 참고해 홈→2루와 2루→중앙 펜스의 1:2 배치를 먼저 비교 대상으로 잡고, 한 화면에서 내야와 공을 읽기 쉬운 1:1로 좁혔다. 바닥은 메시, 외야 펜스는 짧은 직선 조각, 베이스와 라인은 충돌체가 없는 도형으로 구성했다. 현재 대화에서는 첨부 도면을 확인할 수 없어 본문의 배치 규칙을 적용했다.
6. **개선 사항** — 도면이 확보되면 실제 코너 곡률과 홈 입구 형상을 대조한다.

## 판정 홈

1. **적용 대상** — 외야 펜스 9칸, 파울 코너 2곳, 수비 홈 7곳.
2. **적용 이유** — 타구 물리와 판정 규칙을 분리하면서 다음 단계의 공간을 확인할 수 있게 한다.
3. **구조 · 설계값** — 좌측 폴부터 3루타 · 뜬공 아웃 · 1루타 · 2루타 · 홈런 · 2루타 · 1루타 · 뜬공 아웃 · 3루타. 양끝 3루타와 중앙 홈런은 6°씩, 나머지는 12°씩으로 90°를 채운다. 파울 홈은 폴 바깥쪽 코너에 두고 수비 홈은 내야 4개와 외야 3개를 둔다.
4. **장단점** — 색 띠와 얇은 칸막이 표시로 순서와 폭을 비교할 수 있다. 홈의 깊이와 입구 형상은 실제 구슬 크기로 별도 검증해야 한다.
5. **구현 과정** — 외야는 색 띠, 파울 및 수비 위치는 원형 표식으로 표시했다. 외야 펜스와 바닥에 물리 충돌체를 두고 판정 표식에는 충돌체를 두지 않았다.
6. **개선 사항** — 필드 쪽 입구를 둥글게 깎은 실제 홈과 얇은 물리 칸막이를 추가한다. 파울 홈은 낙하를 판정한다. 수비 홈 위치는 고정하고 모형만 좌·중앙·우로 이동시킨다. 모형에 맞은 공은 계속 굴러가고 수비 홈 아래로 떨어졌을 때 아웃을 확정한다.

## 검증 결과

- Unity 6000.3.27f1의 Play 모드에서 중앙선 레이캐스트로 펜스의 필드 쪽 충돌면 Z=16을 확인했다. 씬의 2루 기준점은 Z=8이다.
- 가로 Game 뷰의 배치와 실기기 화면 여백은 검증 예정이다.

## 2026-11-12 · Stadium 모델로 교체

- 실제 씬의 보드와 홈 배치는 가져온 Stadium FBX 기준으로 교체했다. 외야 홈은 5개이며 수비 7개와 파울 2개를 포함한다. 기존 9칸과 1:1은 초기 설계 기록으로 보관한다.
- 적용된 프리팹과 좌표, 충돌체 및 검증 결과는 03-Stadium-Integration.md에 기록했다.
